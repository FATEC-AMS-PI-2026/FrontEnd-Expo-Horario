> Aplicativo mobile desenvolvido para centralizar as informações acadêmicas da Fatec Dom Amaury Castanho – Itu, facilitando o dia a dia de alunos e professores.

## 📌 Sobre o Projeto
Atualmente, alunos e professores dependem de múltiplos sistemas, murais físicos e consultas presenciais para obter horários, localizar professores ou verificar disponibilidade de salas. Este aplicativo reúne todas essas informações em um único ambiente, acessível pelo celular, proporcionando mais agilidade, autonomia e organização.

## ✨ Principais Funcionalidades

- Cadastro e login com e-mail institucional

- Visualização da grade horária individual (aluno/professor)

- Personalização da grade pelo aluno (adição de DPs com verificação de conflitos)

- Consulta em tempo real do status de salas e laboratórios (livre/ocupado)

- Detalhes técnicos da infraestrutura (equipamentos, capacidade) – exclusivo para professores

- Busca por professores com exibição de horários e salas

- Grade de ocupação de cada espaço físico

# Tutorial de Iniciação

## 📋 Pré-requisitos

Antes de começar, verifique se você tem os seguintes itens instalados:

| Item | Descrição |
|------|-----------|
| **Node.js (LTS)** | Disponível em [nodejs.org](https://nodejs.org) |
| **GIT** | Disponivel em [git-scm.com](https://git-scm.com/) |
| **Editor de código** | VS Code (recomendado) ou outro de sua preferência |
| **Expo Go** | Aplicativo instalado no seu dispositivo físico (Android ou iOS) — disponível na Play Store / App Store |

### Passo 1: Verificar as instalações

Abra o terminal e confira se o Node.js está instalado corretamente:

```bash
node -v
```
---
### Passo 2: Clone o repositório

```bash
git clone https://github.com/FATEC-AMS-PI-2026/FrontEnd-Expo
```

> Caso esse passo não funcione, verifique a instalação do git [git-scm.com](https://git-scm.com/) 

---
### Passo 3: acesse o projeto

acesse a pasta do projeto em um editor de código com VSCode ou use o terminal.

```bash
# Acesse o repositório
cd frontend-expo

# Instale as dependencias do projeto
npm install

# Inicie o editor de código
code .

# Inicie o projeto
npx expo start
```
