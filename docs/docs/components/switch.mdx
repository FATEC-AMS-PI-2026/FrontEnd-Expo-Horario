# Switch

Toggle ligado/desligado com opção de label.

## Importação

```tsx
import { Switch } from "../components";
```

## Básico

```tsx
const [ligado, setLigado] = useState(false);

<Switch value={ligado} onValueChange={setLigado} />
```

---

## Com Label

```tsx
const [notificacoes, setNotificacoes] = useState(false);

<Switch
  value={notificacoes}
  onValueChange={setNotificacoes}
  label="Notificações"
/>
```

---

## Props

| Prop | Tipo | Default | Descrição |
|------|------|---------|-----------|
| `value` | `boolean` | - | Estado atual |
| `onValueChange` | `(val: boolean) => void` | - | Callback ao mudar |
| `label` | `string` | - | Label ao lado |
| `className` | `string` | - | Classes adicionais |

---

## Cores

| Estado | Cor |
|--------|-----|
| Ligado | `#005C6E` (primary) |
| Desligado | `#e4e4e7` (border) |
