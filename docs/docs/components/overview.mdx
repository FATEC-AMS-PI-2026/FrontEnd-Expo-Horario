## Como Usar

Todos os componentes estão em `src/components/` e podem ser importados individualmente ou pelo barrel export:

```tsx
// Import individual
import { Button } from "../components/Button";

// Import pelo barrel
import { Button, Card, Input, Badge } from "../components";
```

---

## Estrutura de Arquivos

```
src/components/
  Accordion.tsx    # Accordion e AccordionItem
  Badge.tsx        # Badge com variantes
  Button.tsx       # Botão com variantes e animação
  Card.tsx         # Card, CardHeader, CardContent, CardFooter
  Input.tsx        # Input com ícones e focus state
  Switch.tsx       # Switch com label
  Tabs.tsx         # Tabs e TabPanel com animação
  Text.tsx         # Text com variantes
  index.ts         # Barrel export
```

---

## Animações

Os componentes usam `react-native-reanimated` para animações:

- **Button**: Scale 0.92 no press com spring
- **Tabs**: Indicador desliza com spring
- **Accordion**: Expand/collapse com spring
