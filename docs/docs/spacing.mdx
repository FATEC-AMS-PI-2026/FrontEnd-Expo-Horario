# Espaçamentos

Sistema de espaçamento do design system.

## Escala

O sistema usa uma escala baseada em `4px`.

| Token | Valor | Pixels |
|-------|-------|--------|
| `px-1` | 0.25rem | 4px |
| `px-2` | 0.5rem | 8px |
| `px-3` | 0.75rem | 12px |
| `px-4` | 1rem | 16px |
| `px-5` | 1.25rem | 20px |
| `px-6` | 1.5rem | 24px |
| `px-8` | 2rem | 32px |
| `px-10` | 2.5rem | 40px |
| `px-12` | 3rem | 48px |

---

## Border Radius

| Token | Valor | Uso |
|-------|-------|-----|
| `--radius-sm` | 0.25rem (4px) | Badges, tags pequenas |
| `--radius-md` | 0.375rem (6px) | Inputs, botões pequenos |
| `--radius-lg` | 0.5rem (8px) | Cards, botões |
| `--radius-xl` | 0.75rem (12px) | Cards grandes, modais |

```tsx
// Usando classes do NativeWind
<View className="rounded-sm" />   {/* 4px */}
<View className="rounded-md" />   {/* 6px */}
<View className="rounded-lg" />   {/* 8px */}
<View className="rounded-xl" />   {/* 12px */}
```

---

## Gap

Espaçamento entre elementos flex e grid.

```tsx
<View className="flex-row gap-2">   {/* 8px entre itens */}
  <View />
  <View />
</View>

<View className="flex-col gap-4">   {/* 16px entre itens */}
  <View />
  <View />
</View>
```
