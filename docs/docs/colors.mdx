# Cores

Paleta de cores do design system, definida em `src/theme/index.css`.

Cor principal da marca.

    <code>--color-primary-light</code><br />
    <small>#005C6E</small>
  </div>
  <div style={{ textAlign: 'center' }}>
    <div style={{ width: 80, height: 80, borderRadius: 8, backgroundColor: '#004D5C' }} />
    <code>--color-primary-dark</code><br />
    <small>#004D5C</small>
  </div>
</div>

| Token | Valor | Uso |
|-------|-------|-----|
| `--color-primary` | `#005C6E` | Botões, links, elementos de destaque |
| `--color-primary-light` | `#005C6E` | Variações claras |
| `--color-primary-dark` | `#004D5C` | Estados hover, ênfase |

```tsx
<Button variant="primary">Primary</Button>
```
