# Tipografia

Fontes e estilos de texto do design system.

## Fonte

O projeto usa **Poppins** como fonte principal.

| Peso | Arquivo | Uso |
|------|---------|-----|
| Regular (400) | `Poppins-Regular.ttf` | Corpo de texto |
| Medium (500) | `Poppins-Medium.ttf` | Labels, botões |
| SemiBold (600) | `Poppins-SemiBold.ttf` | Subtítulos |
| Bold (700) | `Poppins-Bold.ttf` | Títulos |

### Variáveis CSS

```css
--font-display: "Poppins-Bold";
--font-body: "Poppins-Regular";
```

### Classes NativeWind

```tsx
// Título
<Text className="font-[Poppins-Bold]">Título</Text>

// Subtítulo
<Text className="font-[Poppins-SemiBold]">Subtítulo</Text>

// Corpo
<Text className="font-[Poppins-Regular]">Corpo de texto</Text>

// Label
<Text className="font-[Poppins-Medium]">Label</Text>
```

---

## Componente Text

O componente `Text` encapsula os estilos de tipografia.

### Props

| Prop | Tipo | Default | Descrição |
|------|------|---------|-----------|
| `variant` | `"heading" \| "subheading" \| "body" \| "caption" \| "label"` | `"body"` | Variante visual |
| `className` | `string` | - | Classes adicionais |

### Exemplos

```tsx
<Text variant="heading">Título Principal</Text>
<Text variant="subheading">Subtítulo</Text>
<Text variant="body">Corpo de texto</Text>
<Text variant="caption">Legenda</Text>
<Text variant="label">Label</Text>
```

### Resultado

| Variante | Tamanho | Peso | Cor |
|----------|---------|------|-----|
| `heading` | 24px | Bold | Preto |
| `subheading` | 18px | SemiBold | Preto |
| `body` | 16px | Regular | Preto |
| `caption` | 14px | Regular | Cinza (#71717a) |
| `label` | 14px | Medium | Cinza (#9ca3af) |
